TANGBIRTHSANGMA — LIVE-READY WEBSITE
====================================

This folder is ready for static hosting such as GitHub Pages.

IMPORTANT:
- This is a static demo. The Owner Login password is only a browser-side demo and is NOT secure.
- A real cross-device owner account requires a backend/authentication service.
- Do not publish your real password, OTP, phone number, address, passport details, or other private information.
- The supplied life-story text is included as the initial published entry.

GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a repository.
3. Upload index.html.
4. Open Settings -> Pages.
5. Choose Deploy from a branch, select main and /(root), then Save.
6. GitHub will provide the live github.io URL after deployment.

See official instructions:
https://docs.github.com/en/pages/quickstart
